# homebrew-tap

Homebrew casks for my macOS apps.

```sh
brew install --cask sumitjha4321/tap/openwhisperflow
```

`sumitjha4321/tap` is shorthand: Homebrew expands it to this repository, because
a tap named `<user>/<name>` lives in `<user>/homebrew-<name>`.

## What's here

| Cask | |
| --- | --- |
| [`openwhisperflow`](Casks/o/openwhisperflow.rb) | Menu bar app for push-to-talk dictation, transcribed on-device — [source](https://github.com/sumitjha4321/openwhisperflow) |

Casks are filed under their first letter (`Casks/o/`), which is the layout
Homebrew's own repositories use.
